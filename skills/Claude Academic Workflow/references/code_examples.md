# Code Examples
Here are some practical code and prompt examples for using Claude in academic tasks:
```markdown
### Literature Review Helper Skill
- **Prompt**: "Generate a literature review on [topic]. Include references from Consensus."
- **Instructions**: "Follow the standard review process with 10 searches. Ensure all references are accurate and relevant."

### Scientific Poster Template
- **Prompt**: "Give me a template of a scientific poster presentation, A0 size."
- **Instructions**: "Include sections for abstract, methods, results, and conclusion. Use deep teal and copper as the color theme."

### Co-Work Task
- **Prompt**: "Perform a literature review on OPV devices."
- **Instructions**: "Use the literature review helper skill and Consensus connector. Provide manual approvals for each step."
```
These examples illustrate how to structure prompts and instructions for various academic tasks using Claude.
