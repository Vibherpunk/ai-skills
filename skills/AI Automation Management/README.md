# Ai Automation Management

Master the skill of managing AI agents like Claude Code to automate tasks, analyze data, and generate insights without requiring technical expertise.

## Setup & Installation

This skill is agent-agnostic and packaged for multiple developer agents. Find your target platform below:

### 💻 Antigravity
_Copy the contents of `platforms/antigravity/` to `~/.gemini/config/skills/AI Automation Management/`._

### 💻 Cursor
_Copy `platforms/cursor/AI Automation Management.mdc` to your project's `.cursor/rules/` directory._

### 💻 Claude
_Append the contents of `platforms/claude/CLAUDE.md` to the target project's `CLAUDE.md` file._

### 💻 Copilot
_Copy `platforms/copilot/AI Automation Management.instructions.md` to your project's `.github/instructions/` directory._

### 💻 Windsurf
_Append the contents of `platforms/windsurf/.windsurfrules` to the target project's `.windsurfrules` file._
