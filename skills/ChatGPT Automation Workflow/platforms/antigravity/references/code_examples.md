# Code Examples
Here are some practical examples of prompts and commands for ChatGPT automation:

1. **Creating a Presentation**:
```plaintext
Create a presentation using the files in this folder: /path/to/project/files
```
2. **Summarizing Emails**:
```plaintext
Summarize my most important emails from the last week.
```
3. **Scheduling a Task**:
```plaintext
Send me this summary every Monday morning.
```
4. **Organizing Desktop**:
```plaintext
Organize my messy desktop.
```

These examples demonstrate how to leverage ChatGPT's capabilities for various automation tasks. Adjust the paths and specifics as needed for your use case.
