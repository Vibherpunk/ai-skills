# Code and Prompt Examples for AI Second Brain

Here are concrete examples of prompts and tasks you can automate using an AI Second Brain.

## Prompt Templates
```plaintext
Prompt: "Summarize today's meeting and draft a follow-up email with next steps."
Prompt: "Turn today's meeting into a project plan and generate a spreadsheet."
Prompt: "Create a presentation based on the discussion from today's meeting."
```

## Example Outputs
1. **Email Draft**: AI generates a follow-up email summarizing the meeting and listing action items.
2. **Spreadsheet**: AI creates a project plan with columns for owner, start date, due date, status, dependency, priority, and notes.
3. **Presentation**: AI generates a polished slide deck based on the meeting discussion.

## Best Practices
- **Be Specific**: Clearly define the task or question to get the most accurate results.
- **Leverage Context**: Use the AI's understanding of your data to automate complex tasks.
